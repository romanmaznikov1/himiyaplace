# himiyaplace

## Блог

Статьи лежат в `content/blog/*.md`, страницы в `blog/` собираются из них — руками `blog/` не правим.

```sh
node tools/build-blog.mjs        # пересобрать блог, sitemap.xml и блок «Полезное» на главной
node tools/build-blog.mjs --og   # плюс картинки-превью для соцсетей (нужен Google Chrome)
```

- Новая статья — новый `.md` с тем же набором полей в шапке, что у остальных.
- Расписание в статьях (`{{schedule: High Heels}}`, `{{schedule-week}}`) берётся из `index.html`: поменяли расписание на главной — пересоберите блог.
- Цены — в `PRICES` в начале `tools/build-blog.mjs`: из них собираются и раздел «Цены» на главной (между `<!-- prices:start -->` и `<!-- prices:end -->`, руками не править), и таблица `{{prices}}` в статьях.
- `featured: 1…4` — статья попадает в блок «Полезное» на главной.
